Physical Release Studio - GOG Disc Creator (V5)

Dateien
- Physical-Release-Studio-GOG-Disc-Creator.html  Das Tool fuer die Webseite (eine Datei, Launcher eingebettet, kein Upload von Spieldaten).
- GOGAutoLauncher.exe                            Derselbe Launcher einzeln (zum Testen).
- Quellcode-Launcher/                            Go-Quellcode. Build:
    GOOS=windows GOARCH=amd64 go build -trimpath -ldflags="-s -w -H windowsgui" -o GOGAutoLauncher.exe .
    python patch_pe.py GOGAutoLauncher.exe      (Disc-Wechsel-Schutz), danach EXE per Base64 in die HTML (EMBEDDED_GOG_LAUNCHER_B64) einsetzen.
    Tests der Disc-Logik: go test ./core/

Ablauf fuer Nutzer
- Normalmodus: jede .bin bleibt ganz auf einer Disc. Start von Disc 1, das Setup fragt selbst nach der naechsten Disc.
- Grosse .bin (groesser als das Medium, z.B. CD-R): der Creator zerlegt sie, der Launcher kopiert alle Discs nacheinander
  (automatische Disc-Erkennung) auf die Festplatte und startet dann das Setup.
- Optional bei mehreren Discs: "Erst auf die Festplatte kopieren", nur angeboten wenn genug freier Platz da ist.

Noch nicht getestet: der Launcher auf echtem Windows mit gebrannten Discs (nur kompiliert, Code-Review, Logiktests unter Linux).
