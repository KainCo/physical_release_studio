Datenschutzerklärung

Steam Disc Creator · Stand: November 2026

1. Kurz gesagt

Der Steam Disc Creator arbeitet vollständig lokal in Ihrem Browser. Ordner und Dateien, die Sie auswählen, werden nicht hochgeladen. Wir setzen keine Cookies, kein Tracking und keine Analyse-Dienste ein und laden keine Schriften, Skripte oder Bilder von Dritten nach. Beim reinen Aufruf der Seite verarbeitet der Hosting-Anbieter technisch bedingt Ihre IP-Adresse (siehe Abschnitt 3).

2. Verantwortlicher

Verantwortlich ist KainCo Productions. Anschrift und Kontaktmöglichkeiten finden Sie im Impressum.

3. Hosting (GitHub Pages)

Diese Seite wird über GitHub Pages ausgeliefert (Anbieter: GitHub, Inc., 88 Colin P Kelly Jr St, San Francisco, CA 94107, USA). Beim Aufruf erfasst GitHub technisch bedingt Server-Logfiles einschließlich Ihrer IP-Adresse. Details: Datenschutzerklärung von GitHub.

Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse an einer sicheren und zuverlässigen Auslieferung der Seite). Eine Übermittlung in die USA kann nicht ausgeschlossen werden; zu den eingesetzten Garantien informiert GitHub in seiner Datenschutzerklärung. Wir speichern selbst keine Logfiles und haben keinen Zugriff darauf; die Speicherdauer richtet sich nach den Richtlinien von GitHub.

Wenn Sie das Tool von GitHub Releases oder aus dem Quellcode-Repository herunterladen, gelten für den Download ebenfalls die Bedingungen von GitHub.

4. Lokaler Speicher (Local Storage)

Wir speichern in Ihrem Browser ausschließlich Ihre gewählte Sprache (Schlüssel prs_lang). Der Eintrag ist für die von Ihnen gewünschte Funktion unbedingt erforderlich (§ 25 Abs. 2 Nr. 2 TDDDG), wird nicht an uns übertragen und bleibt auf Ihrem Gerät. Sie können ihn jederzeit in Ihrem Browser löschen.

5. Verarbeitung im Tool

Der gewählte Spielordner wird ausschließlich lokal auf Ihrem Gerät gelesen. Ordnernamen, Dateinamen, Pfade und Dateiinhalte werden nicht an uns oder an Dritte übertragen. Das Gleiche gilt für Ihr Banner-Bild und eine optionale Steam-Manifestdatei.

Die Hinweise zum Kopierschutz entstehen lokal aus den Dateinamen im Ordner und aus den Abschnittsnamen der Programmdateien. Es findet kein Abgleich mit einer Online-Datenbank statt und es wird keine Anfrage an Dritte gesendet. Die Hinweise sind unverbindlich und ersetzen keine Prüfung.

Das erzeugte Paket (Ordner oder ZIP-Dateien) wird auf Ihrem Gerät erstellt. Es wird nichts an uns übermittelt.

6. Der erzeugte Installer (Launcher.exe)

Der Installer baut von sich aus keine Internetverbindung auf und enthält keine Telemetrie. Er arbeitet nur mit lokalen Dateien. Auf Ihrem Rechner kann er Folgendes anlegen:

  • die Spieldateien im von Ihnen gewählten Zielordner, dazu uninstall.exe und prs_uninstall.log (Liste der angelegten Dateien für die Deinstallation);
  • einen Eintrag unter „Apps & Features“ in der Windows-Registrierung (nur für den aktuellen Benutzer, HKEY_CURRENT_USER), damit eine vorhandene Installation erkannt und deinstalliert werden kann;
  • auf Wunsch Verknüpfungen auf dem Desktop und im Startmenü;
  • im Steam-Modus: lesender Zugriff auf den Steam-Pfad in der Registrierung und die Datei libraryfolders.vdf, um Bibliotheksordner vorzuschlagen; die mitgelieferte oder eine einfache selbst erzeugte Datei appmanifest_<AppID>.acf im Ordner steamapps; die Datei steam_appid.txt neben der Programmdatei, wenn eine AppID angegeben wurde und die Datei fehlt.

Diese Angaben verlassen Ihren Rechner nicht. Beim Start eines Spiels über Steam wird nur eine steam://-Adresse an den Steam-Client übergeben; dessen eigene Datenverarbeitung unterliegt den Bedingungen von Valve.

Optional mitinstallierte Komponenten (z. B. Visual C++, DirectX, .NET) sind Programme Dritter, die erst nach Ihrer Auswahl und mit Administratorabfrage ausgeführt werden. Für deren Verhalten ist der jeweilige Hersteller verantwortlich.

7. Links zu externen Angeboten

Das Tool enthält einen Link zu PCGamingWiki (pcgamingwiki.com), über den Sie nachschlagen können, ob ein Spiel DRM-frei ist. Eine Verbindung zu PCGamingWiki entsteht erst, wenn Sie den Link aktiv anklicken. Die dabei übermittelte Spiel-ID oder der Titel dient nur der Suche. Ab dem Klick gelten die Datenschutzbestimmungen von PCGamingWiki. Wir erhalten dadurch keine Daten über Sie.

Sie haben im Rahmen der gesetzlichen Vorgaben das Recht auf Auskunft (Art. 15 DSGVO), Berichtigung (Art. 16), Löschung (Art. 17), Einschränkung der Verarbeitung (Art. 18), Datenübertragbarkeit (Art. 20) sowie Widerspruch gegen Verarbeitungen auf Grundlage von Art. 6 Abs. 1 lit. f DSGVO (Art. 21). Privacy Policy

Steam Disc Creator · As of: November 2026

1. In short

The Steam Disc Creator runs entirely locally in your browser. Folders and files you select are not uploaded. We use no cookies, no tracking and no analytics, and we load no fonts, scripts or images from third parties. When you simply open the page, the hosting provider processes your IP address for technical reasons (see section 3).

2. Controller

The controller is KainCo Productions. Address and contact details are in the Legal Notice.

3. Hosting (GitHub Pages)

This page is delivered via GitHub Pages (provider: GitHub, Inc., 88 Colin P Kelly Jr St, San Francisco, CA 94107, USA). When you open it, GitHub records server log files including your IP address for technical reasons. Details: GitHub's privacy statement.

The legal basis is Art. 6(1)(f) GDPR (legitimate interest in delivering the page securely and reliably). A transfer to the USA cannot be ruled out; GitHub describes the safeguards it uses in its privacy statement. We do not store any log files ourselves and have no access to them; retention follows GitHub's policies.

If you download the tool from GitHub Releases or from the source repository, GitHub's terms also apply to the download.

4. Local storage

The only thing stored in your browser is your chosen language (key prs_lang). It is strictly necessary for the function you requested (Section 25(2) no. 2 TDDDG), is not transmitted to us and stays on your device. You can delete it in your browser at any time.

5. Processing in the tool

The game folder you choose is only read locally on your device. Folder names, file names, paths and file contents are not transmitted to us or to third parties. The same applies to your banner image and an optional Steam manifest file.

The copy-protection hints are produced locally from the file names in the folder and from the section names of the executables. There is no comparison with an online database and no request is sent to third parties. The hints are non-binding and are no substitute for checking.

The generated package (folder or ZIP files) is created on your device. Nothing is sent to us.

6. The generated installer (Launcher.exe)

The installer does not open an internet connection on its own and contains no telemetry. It only works with local files. On your computer it may create:

  • the game files in the target folder you choose, plus uninstall.exe and prs_uninstall.log (a list of created files used for uninstalling);
  • an entry under "Apps & features" in the Windows registry (current user only, HKEY_CURRENT_USER) so that an existing installation can be detected and uninstalled;
  • optionally, shortcuts on the desktop and in the Start menu;
  • in Steam mode: read access to the Steam path in the registry and to libraryfolders.vdf to suggest library folders; the bundled or a simple self-generated appmanifest_<AppID>.acf in the steamapps folder; the file steam_appid.txt next to the program file if an AppID was given and the file is missing.

This information does not leave your computer. When a game is started through Steam, only a steam:// address is handed to the Steam client; its own data processing is governed by Valve's terms.

Optionally installed components (e.g. Visual C++, DirectX, .NET) are third-party programs that only run after you select them and with an administrator prompt. Their respective vendors are responsible for their behaviour.

7. Links to external services

The tool contains a link to PCGamingWiki (pcgamingwiki.com) where you can look up whether a game is DRM-free. A connection to PCGamingWiki is only made once you actively click the link. The game ID or title passed along is used only for the search. From the click on, PCGamingWiki's privacy terms apply. We receive no data about you through it.

8. Your rights

Within the framework of the law you have the right of access (Art. 15 GDPR), rectification (Art. 16), erasure (Art. 17), restriction of processing (Art. 18), data portability (Art. 20) and to object to processing based on Art. 6(1)(f) GDPR (Art. 21). You can also lodge a complaint with a data protection supervisory authority (Art. 77 GDPR).

Since we do not store personal data ourselves, we can usually only provide information on details we hold because you contacted us. For the server log files, please contact GitHub. For privacy matters you can reach us via the contact details in the Legal Notice.
