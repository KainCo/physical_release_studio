Steam Disc Creator

Macht aus einem Spielordner ein Paket für CD, DVD, Blu-ray oder USB: Das Tool teilt die Dateien bei Bedarf auf mehrere Discs auf, und ein kleiner Installer fügt sie später wieder zusammen. Er kann das Spiel installieren, erkennt eine vorhandene Installation („Spiel starten“) und bringt einen Uninstaller mit.

Alles bleibt auf deinem Rechner Die Dateien werden ausschließlich lokal in deinem Browser gelesen. Es wird nichts hochgeladen, und das Tool lädt keine Inhalte von Dritten nach. Der erzeugte Installer baut ebenfalls keine Internetverbindung auf.

1Spielordner wählen

Wähle den Ordner des Spiels, z. B. …\steamapps\common\Spielname. Er wird nicht verändert.

2DRM-Hinweise

Im PCGamingWiki nachschlagen ↗ – öffnet pcgamingwiki.com in einem neuen Tab. Erst nach deinem Klick wird eine Verbindung aufgebaut.

Der sicherste Test: Beende Steam und starte das Spiel direkt aus dem Spielordner. Startet es, ist es für dich ohne Steam nutzbar.

3Einstellungen

Mit der AppID legt der Installer die Datei steam_appid.txt an, falls sie fehlt. Du findest die AppID in der Steam-Adresse des Spiels (store.steampowered.com/app/…).

Die Manifest-Datei liegt in steamapps neben dem Ordner common. Mit ihr erkennt Steam das Spiel nach der Installation oft sofort als vorhanden. Ungetestet: Steam kann trotzdem eine Überprüfung der Dateien verlangen.

Verwende dein eigenes Bild (JPG oder PNG). Empfohlen sind mindestens 920 × 430 Pixel; der Installer skaliert auf 640 Pixel Breite.

4Medium und Berechnung

Berechnet mit 2-KiB-Sektoren, Verzeichnis-Overhead pro Datei und 1 % Reserve. Brenne mit dem Dateisystem UDF (bei CDs ist ISO 9660/Joliet auf 64 Zeichen pro Name begrenzt).
